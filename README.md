# OUTPOST. / A Mars Experience

A real-time Three.js reconstruction inspired by the supplied Mars landing reference. The scene contains two metallic cargo landers, an articulated astronaut, supply rovers, and a textured, procedurally modeled landscape. All scenery is actual 3D geometry, not a background image.

## Controls

- WASD or arrow keys: walk relative to the camera.
- Shift: run.
- Space: jump with simulated Martian gravity.
- Click and drag: look around.
- Scroll: adjust camera distance.
- C: switch between third-person and orbit views.
- E: inspect a nearby site and access its cargo controls.
- R: reset the astronaut and camera.
- Escape: close a panel.

Touch devices have a directional pad, jump button, and drag-to-look controls after beginning exploration. The map supports setting waypoints and traveling directly to any site. Discoveries are saved locally in the browser. Ambient wind audio starts only when enabled by the user.

## Implementation

- `src/App.tsx`: React interface, map and mission state, dialogs, and settings.
- `src/experience/MarsEngine.ts`: render loop, movement, collision handling, animation, and cameras.
- `src/experience/world.ts`: procedural scenery, vehicles, astronaut, materials, and lighting.
- `src/components/SiteMap.tsx`: interactive position-aware site map.
- `public/textures/mars-regolith.jpg`: generated surface texture.

The experience requires a WebGL 2 browser. Balanced quality mode disables shadows and reduces pixel resolution for lower-powered devices. The landscape, vehicle specifications, local time, and mission inventory are an imagined expedition rather than live telemetry from Mars.

Run the Vite development server with `npm run dev`. Production output is generated by `npm run build`.
